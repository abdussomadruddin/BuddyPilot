# BuddyPilot Poster (Chrome extension)

Puts a post you sent from Post Pilot ("Facebook personal") into Facebook's post
box, with its photo if it has one. You press Post yourself. It can also read the
engagement shown on your own profile so Post Pilot learns from personal posts.

## Install
1. Chrome > `chrome://extensions` > turn on Developer mode.
2. Load unpacked > choose this `extension` folder.
3. BuddyPilot > Post Pilot > Tetapan > Jana token extension. Copy the token.
4. Click the BuddyPilot Poster icon in Chrome, paste the token, Simpan.

## Use
- In Post Pilot press **Facebook personal**. In Chrome, open the extension and
  press **Isi di Facebook**, check the post, press Post on Facebook, then
  **Dah post**.
- On your own profile, scroll so posts are visible and press
  **Sync engagement**.

Reading Facebook's page depends on Facebook's layout and may need updating when
Facebook changes it. If the post box is not found, the text is already copied:
open the box and paste.
